# Решение (ADR) — шаблон

**Назначение.** Запись развилки и выбора, чтобы решение **не переигрывали заново** через месяц. Самая
ценная часть — не выбранный вариант, а отвергнутые с причинами: без них спор начнётся с нуля, и второй
раз может выиграть уже отвергнутое.

**Автор:** любой участник. **Принимает:** ревьюер (ворота `G2`).

## Требования к содержанию

- **Развилка описана до выбора.** Решение, в котором нет альтернатив, — это не решение, а описание
  сделанного.
- **Отвергнутые варианты с причиной отказа.** Причина конкретная: «не проходит по времени отклика на
  замере X», а не «сложно».
- **Последствия названы обеими сторонами:** что стало проще и что стало дороже. Решение без цены
  подозрительно — цену просто не искали.
- **Каждая ссылка подтверждена чтением цитируемого места**, а не смыслом документа. Это отдельный класс
  ошибки — «метка вместо содержимого»: утверждение верное, но подпёрто не тем источником. Цена высокая,
  потому что решение цитируется дальше и ошибка размножается.
- **Номер берётся свободным непосредственно перед публикацией**, а не при создании файла. В проекте с
  несколькими исполнителями номер уходит за час, и переименование тем дороже, чем позже обнаружено:
  имя файла, заголовок, строка реестра, ссылки из норм и описаний.
- **Статус живёт в самом решении:** предложено / принято / заменено (ссылка на заменившее). Отменённое
  решение не удаляется — оно объясняет, почему код такой.

## Шаблон

```markdown
# ADR-<NNNN>: <решение одной фразой в утвердительной форме>

> **Статус:** предложено / принято <дата> / заменено <ссылка>
> **Принял:** <имя> | **Автор:** <имя>

## Контекст
<Что вынудило выбирать. Факты и числа, без оценок.>

## Развилка
| Вариант | Плюсы | Минусы | Отвергнут потому что |
|---|---|---|---|
| A (выбран) | | | — |
| B | | | <конкретная причина> |
| C | | | |

## Решение
<Что делаем. Утвердительно, в настоящем времени.>

## Последствия
| Стало проще | Стало дороже |
|---|---|

## Ссылки
| Утверждение решения | Источник | Проверено чтением |
|---|---|---|
| <цитата или тезис> | <файл:строка / документ, раздел> | да, <дата> |
```

## Критерий передачи (проверяет автор)

- [ ] в развилке не меньше двух альтернатив, и у каждой отвергнутой названа конкретная причина;
- [ ] последствия заполнены с обеих сторон;
- [ ] **каждая ссылка открыта и прочитана**, отметка стоит; ссылок «по смыслу документа» нет;
- [ ] номер взят свободным перед публикацией и проверен ещё раз (в реестре, в открытых MR, в основной ветке);
- [ ] упоминания номера согласованы: имя файла, заголовок, строка реестра.

## Критерий приёмки (проверяет ревьюер, `G2`)

- [ ] я понимаю, почему выбран этот вариант, не расспрашивая автора;
- [ ] отвергнутые варианты действительно рассматривались, а не дописаны для формы;
- [ ] ссылки ведут туда, где сказано именно это — проверил хотя бы две выборочно;
- [ ] решение не противоречит принятым ранее, либо явно заменяет одно из них ссылкой.
