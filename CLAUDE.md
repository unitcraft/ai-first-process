# Репозиторий методологии AI-first разработки

Здесь нет кода продукта — только нормы, шаблоны артефактов и планы их введения. Что где лежит и с
чего начинать чтение — [README.md](README.md). Этот файл про то, **как здесь работать**.

## Главное обещание репозитория

**Материал переносится в любой проект как есть.** Из этого следует всё остальное: ни имён заказчиков и
организаций, ни абсолютных путей, ни секретов, ни персональных данных, ни примеров из конкретного
проекта. Каждое такое упоминание делает файл непереносимым, а переносимость здесь — единственный смысл
существования.

Обещание ломается молча, поэтому проверяется машиной, а не памятью:

```bash
bash scripts/guard.sh        # проверки; молчит, когда чисто, код 1 при нарушениях
bash scripts/guard-test.sh   # тест на самого стража: срабатывание и молчание
bash scripts/install-hooks.sh # поставить pre-commit — после КАЖДОГО нового клона
```

**Каталог `.git/hooks` не версионируется**, поэтому после клонирования хука нет и страж перестаёт быть
обязательным ровно тогда, когда за репозиторий садится новый человек. Первое действие в свежем клоне —
`install-hooks.sh`.

## Что проверяет страж

Восемь проверок, и каждая — из класса «нарушается молча»: управляющие байты (делают строку невидимой
для поиска), абсолютные пути, похожее на секрет присвоение, чужие имена по локальному списку, битые
относительные ссылки, старая терминология, форма шаблонов, расхождение реестра шаблонов с файлами.

**Список чужих имён — `.denylist` в корне, он в `.gitignore`:** сам список публикации не подлежит по той
же причине, по какой не подлежат имена в тексте. Списка нет — проверка **говорит о пропуске вслух**, а
не молчит: молчаливый пропуск читается как «чисто».

## Правила письма

- **Имена файлов и каталогов английские, содержание русское.** Имя должно переноситься в проект любой
  команды без перевода, текст — читаться теми, кто работает.
- **Нормы отдельно от планов.** `methodology/` живёт и правится, `plans/` закрывается. Норма, попавшая
  внутрь плана, умирает вместе с его закрытием — на этом уже обожглись, разделение куплено ошибкой.
- **Один факт — один дом.** В остальных местах ссылка, а не копия: два адреса одного знания расходятся
  молча, и оба выглядят достоверно.
- **Норма без наблюдённого случая нарушения не вводится.** Такие нормы не соблюдают, и они
  обесценивают соседние.
- **Правило, нарушенное дважды, переписывается или механизируется** — не повторяется третий раз.
- **Терминология: контрольные точки `КТ1`…`КТ8`.** Прежнее слово и прежние буквенные токены запрещены
  и проверяются стражем — чтобы переименование не отползло обратно при следующей правке.
  Запрещены именно «ворота» и `G0`…`G7`. <!-- страж: цитата -->
  Пометка стоит на этой строке, потому что оговорка действует **на строку, а не на файл**: документ,
  объявляющий запрет, обязан запрещённое назвать, но исключённый целиком файл перестал бы
  проверяться и на настоящем откате правила.

## Как добавить

**Шаблон артефакта:** файл в `templates/` с четырьмя обязательными разделами — требования, шаблон,
критерий передачи, критерий приёмки — плюс строка в реестре `templates/README.md`. Обе стороны
проверяются стражем: файл без строки не найдут, строка без файла — обещание впустую.

**Норму:** в подходящий файл `methodology/`, а не новым файлом по каждому поводу. Новый файл заводится,
когда у нормы появляется свой предмет, и тогда же вносится в карту `methodology/README.md`.

**План:** `plans/NNN-<slug>.md`. Обязательные разделы, статусы и форма — по образцу
[001](plans/001-ai-first-methodology.md), пока не написана отдельная конвенция (это `Ф.3` того же плана).

## Ловушки окружения, купленные здесь

- **`grep -i` не сворачивает регистр кириллицы** (`LANG` пуст): слово с заглавной не находится по
  строчному написанию. <!-- страж: цитата --> Так «Ворота» пережило сквозную замену 04.09.2026 —
  заголовок столбца остался, а проверка молчала. Проверки по русскому тексту идут через
  `perl -CSD -Mutf8`, а не `grep -i`.
- **`perl` без `use utf8` сравнивает кириллический литерал побайтово** с декодированным текстом и не
  находит ничего — при этом выглядит работающим. Первая версия проверки формы шаблонов давала «0 из 4»
  у всех файлов, а проверка терминологии молчала бы на нарушении. Нужны оба ключа: `-CSD` и `-Mutf8`.
- **Сообщение коммита, переданное через heredoc или stdin, теряет последнюю строку.** Так дважды
  пропадала подпись. Сообщение длиннее строки пишется в файл и передаётся `git commit -F <файл>`;
  после коммита последняя строка проверяется: `git log -1 --format=%B | tail -1`.

## Что здесь не заводится

Лицензия, публикация в открытый доступ, перевод на другие языки, привязка к конкретному инструменту
или вендору. Репозиторий приватный и личный; всё перечисленное — отдельные решения, а не побочный
эффект правки.
